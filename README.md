# 我看见的世界 — Audiobook Studio (iPhone PWA)

Public URL: `https://ShaunDataAnalytics.github.io/the-worlds-i-see-studio/`

Modeled directly after [The Mom Test Studio](https://ShaunDataAnalytics.github.io/mom-test-studio/).

## 📲 iPhone Installation (Safari)
1. Open `https://ShaunDataAnalytics.github.io/the-worlds-i-see-studio/` in **Safari** on your iPhone.
2. Tap **Share** (box with up arrow) → **Add to Home Screen**.
3. The custom icon will appear on your iPhone screen for full-screen offline playback!
   - 100% offline via Service Worker.
   - Native audio playback with speed controls & chapter teleprompter.
